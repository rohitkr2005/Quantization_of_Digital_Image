How does it work?

In digital image processing, quantization determines how many distinct intensity levels a pixel can have. The number of levels is 2n, where n is the bit depth.

For example, a 1-bit image has only 2 shades (black & white), while an 8-bit image has 256 shades — enough for smooth gradients. As you decrease the bits, you can clearly see the visible "banding" effect known as false contouring.
